## 👋 Что это такое

FusaFP подключается к вашему аккаунту FunPay и переносит основные действия в Telegram. Не нужно держать сайт открытым: новые сообщения и заказы приходят в бота за несколько секунд, а ответить покупателю можно не вставая с дивана.

## ✨ Что умеет бот

### 💬 Чаты с покупателями
- Читайте сообщения покупателей и отвечайте им прямо из Telegram
- Ответ можно отправить обычным сообщением в открытом чате или реплаем на уведомление
- Автоответ новым покупателям с настраиваемым текстом
- После выхода из чата переписка из Telegram убирается, чтобы не копился мусор

### 🐇 Лоты
- Поднятие лотов вручную или автоматически
- Таймер: видно, когда будет следующее поднятие
- Управление лотами: отключать, восстанавливать и удалять
- Автовосстановление лотов после продажи
- Автодеактивация лота, когда товар закончился

### 📦 Заказы и выдача
- Список заказов, отметка выдачи и возврат
- Автовыдача товаров со склада с вашим текстом
- Подтверждение заказов, в том числе заявка в поддержку FunPay

### 📊 Деньги и статистика
- Баланс и вывод средств
- Статистика по аккаунту

### 🔔 Уведомления без спама
- Одно уведомление на человека: сколько бы сообщений он ни написал, пока вы не открыли чат, новых уведомлений не будет
- Напоминание о непрочитанных чатах раз в 15 минут
- Каждый тип уведомлений включается отдельно: поднятие лотов, заказы, выдача товара, новые сообщения, напоминания

### 🧩 Дополнительно
- Плагины для расширения возможностей
- Настройки автоматизации под ваш стиль работы
- Несколько пользователей: каждый подключает свой аккаунт, данные хранятся отдельно

## 🚀 Как начать

1. Откройте бота: **[@FusaFP_bot](https://t.me/FusaFP_bot)**
2. Нажмите **Start** и следуйте подсказкам
3. Подключите аккаунт FunPay
4. Откройте «⚙️ Настройки» и настройте бота под себя

## 🔐 Безопасность

- Бот **никогда не просит** пароль от FunPay, коды 2FA, данные карт и CVV. Если кто-то просит такое от имени бота, это мошенники
- Данные для работы с аккаунтом хранятся в зашифрованном виде
- Удалить свои данные можно в любой момент: «⚙️ Настройки» → «🗑 Удалить мои данные»
- Для полного отзыва доступа дополнительно выйдите из аккаунта FunPay в браузере
